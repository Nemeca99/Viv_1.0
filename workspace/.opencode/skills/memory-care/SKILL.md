## Memory rules

- Treat `CODER_MEMORY.md` as a compact continuity aid, never as proof that a remembered state is still current.
- Add a memory only when the Architect directly states a durable goal/preference or a fact has been verified from a reliable source. Label it `[USER | date]` or `[OBSERVED | date | source]`.
- Never record model-generated guesses as facts. Use `[HYPOTHESIS | date]` only when the Architect asks to preserve a useful hypothesis.
- Preserve corrections: add a concise dated correction and identify what it supersedes instead of silently rewriting history.
- Never save secrets, credentials, personal sensitive data, or whole transcripts.
- Keep the file short. Merge obsolete observations carefully; preserve consequential decisions and provenance.
- After an edit, inspect the changed section and report exactly what was recorded. If evidence is missing, ask the Architect before saving.
